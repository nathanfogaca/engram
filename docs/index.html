O palco

Agentes que conversam pela linha que você desenha

  • ♛
    Um maestro rege o time

    Você pede ao maestro, ele divide o trabalho, manda para quem está ligado a ele e junta os resultados.

  • ⇄
    Linhas são conversas

    Arraste uma linha entre dois cartões e eles passam a trocar mensagens, que você vê correndo pela linha.

    Um modelo forte para analisar, um leve para tarefas simples, um Codex ao lado de um Claude. Você escolhe por janela.

O cérebro

Uma memória que vira rede de neurônios

Cada nota é um neurônio. Ligações viram fibras, e quando um agente lê ou grava uma nota, o impulso corre até ela. Casos e memórias de um lado; sistemas, tabelas e projetos do outro.

  • ⚡
    Vivo de verdade

    De vez em quando um neurônio dispara sozinho, e o impulso acende os vizinhos em cascata.

  • ◎
    Veja quem leu o quê

    Os agentes ficam embaixo, como o tronco do cérebro, ligados às notas que tocaram.

  • ⌕
    Busque e navegue

    A busca acende as notas encontradas; clique num neurônio para abrir a nota.

  • ◌
    O que falta documentar

    Notas citadas que ainda não existem aparecem como neurônios fantasmas.

Recursos

Tudo o que um time de agentes precisa

Feito para o dia a dia: agentes de verdade, ferramentas de verdade e uma memória que cresce com o uso.

✺

Um cérebro que fica com você

Notas em Markdown ligadas por [[id]]: chamados, tabelas, padrões, sistemas e projetos. Os agentes leem antes de investigar do zero e gravam o que aprendem. Você vê tudo como uma rede de neurônios, com cada agente ligado às notas que tocou.

❝

Conversa legível, sem gastar token

Cada cartão mostra a conversa em texto, lida do arquivo que o próprio agente grava. Abra no leitor grande, acompanhe as mensagens entre colegas e mande arquivos: logs, prints e planilhas entram e o agente devolve o que fez.

⇄

MCPs fáceis

Cadastre servidores MCP (HTTP ou programa local), teste a conexão, ligue e desligue, escolha para quais agentes vale. Traga os que você já configurou no Claude Code e no Codex.

✦

Skills do seu jeito

Uma biblioteca de skills no formato SKILL.md, com editor e prévia ao vivo. Importe .zip ou .skill, ligue, desligue e escolha Claude ou Codex.

◉

Suas contas, seus agentes

Entre em cada CLI pela própria tela, num terminal de verdade, ou use uma chave de API guardada no cofre do Windows. Instale o que falta com um clique.

＋

Abrir um agente leva dois segundos

Escolha o agente (Claude Code, Codex…), o modelo, o papel (maestro, revisor, redator, bibliotecário) e os MCPs daquela janela. Ele aparece no palco pronto para ligar.

⌕

Busca e consulta no cérebro

Ctrl+K encontra qualquer nota pelo texto, sem acento e sem esforço. Para quem gosta, a aba Consulta roda SQL só de leitura no índice do cérebro.

O time não cai

Fechou o app? Atualizou? Os agentes continuam trabalhando.

Os agentes rodam num motor separado do aplicativo. Fechar a janela, reiniciar ou instalar uma versão nova não derruba ninguém: quando o Engram volta, ele reencontra o time e a conversa continua de onde parou. Se o motor cair, ele reabre cada agente na mesma conversa.

Seu, de verdade

Local, aberto e com as chaves no cofre

🖥️Roda no seu PC

Os agentes, o cérebro e os arquivos ficam no seu computador. O cérebro é uma pasta de notas que você pode abrir em qualquer editor.

🔐Chaves no cofre

Chaves de API e tokens de MCP vão para o Gerenciador de Credenciais do Windows, nunca para um arquivo de texto.

🔒Porta fechada

A tela fala com o app por dentro. O servidor dos agentes escuta só em 127.0.0.1 e exige token.

📖Código aberto

Tudo está no GitHub. Sem conta no Engram e sem coleta de dados: você usa as contas dos agentes que já tem.

Perguntas

Perguntas frequentes

Preciso pagar alguma coisa?

O Engram é grátis. Os agentes usam as suas próprias contas (Claude, ChatGPT, Google…) ou as suas chaves de API, com os limites e preços de cada provedor.

Quais agentes funcionam?

Claude Code e Codex funcionam completos, inclusive no mesmo time. Gemini CLI e OpenCode já entram no palco e estão marcados como experimentais. O Engram detecta o que está instalado e oferece instalar o resto.

O Windows mostrou "editor desconhecido". É normal?

Sim. O instalador ainda não tem certificado de assinatura, então o SmartScreen avisa na primeira vez. Clique em "Mais informações" e em "Executar assim mesmo". O código de cada versão está no GitHub.

Os agentes param quando eu fecho o app?

Não. Fechar a janela deixa o Engram na bandeja, e mesmo saindo do app os agentes seguem no motor. Ao abrir de novo, o time está lá, com a conversa onde parou.

Onde ficam as notas do cérebro?

Numa pasta do seu computador (por padrão, em %APPDATA%\Engram\cerebro), em arquivos Markdown. Dá para apontar para outra pasta ou para um servidor próprio nos Ajustes.

Posso usar os MCPs e skills que já tenho?

Pode. Em Ajustes, as abas MCPs e Skills listam o que já está configurado no Claude Code e no Codex, e um clique traz para o Engram (tokens vão para o cofre do Windows).
